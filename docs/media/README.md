# Demonstração do aplicativo

- [Vídeo completo](demo-completo.mp4): aproximadamente 7min15s, H.264/AAC, arquivo 1920 × 1080, 24 fps, 19 capítulos.
- [Legendas pt-BR](legendas.srt): também presentes como faixa opcional no MP4.
- [Roteiro](roteiro.md): conteúdo da narração.
- [Painel](painel.jpg), [execuções](execucoes.jpg) e [plano do piloto](piloto.jpg): capturas da interface.

É uma montagem narrada de capturas reais da versão integrada que deu origem ao pacote independente, não uma gravação contínua. Dados e voz são sintéticos. A resolução do contêiner de vídeo não implica captura nativa de todo texto fino da interface nessa resolução; a qualidade das telas acompanha a captura fornecida pelo navegador.

Não há chave privada, senha ou cookie exposto nos quadros. O fluxo positivo de verificação usa um pacote sintético para ilustrar o mecanismo; em auditoria real, o checkpoint precisa ter sido retido por um canal independente. Consulte [CRYPTOGRAPHY](../CRYPTOGRAPHY.md).

O GitHub pode oferecer download em vez de player para o MP4. Abra-o em um player compatível para usar legendas e capítulos. O vídeo não é carregado pelo aplicativo em runtime.
