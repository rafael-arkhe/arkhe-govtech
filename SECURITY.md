# Relato de segurança

Este projeto é um MVP local de validação. Não há certificação de segurança ou promessa de adequação para operação pública real.

Não abra um issue público com senhas, chaves, cookies, dados pessoais, documentos institucionais ou pacotes de auditoria reais. Se o recurso de relato privado do GitHub estiver disponível neste repositório, prefira-o. Caso contrário, abra apenas um pedido de contato sem detalhes sensíveis para combinar um canal apropriado com o mantenedor.

Um relato útil inclui versão/commit, ambiente, pré-condições, impacto e reprodução com dados sintéticos. Preserve evidências sem executar efeitos em sistemas de terceiros.

Consulte o [modelo de ameaças](docs/SECURITY-MODEL.md) para a fronteira de confiança. Conta local/assinatura Ed25519 não é identidade estatal, e a cadeia local não protege contra administrador malicioso do host sem checkpoint externo confiável.

Não há prazo contratual de resposta ou programa de bug bounty estabelecido neste documento.
